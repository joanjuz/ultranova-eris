Conexión con GitHub

Introduce el repositorio donde estará publicada la web. El token se usa únicamente en esta sesión y no se incorpora al sitio ni a los archivos JSON.

No se guarda en localStorage ni se envía a servicios ajenos a la API de GitHub. Caduca según la configuración que establezcas en GitHub.
Conecta un repositorio para poder publicar.

Vídeos capturados del romhack

Elige una entrada de Movimientos y sube su clip grabado. Se alojará dentro del repositorio, en la carpeta de medios de la web.

Recomendación: clips cortos y comprimidos, hasta 10 MB por archivo en este editor.

El clip se vincula automáticamente a la ficha seleccionada, pero debes publicar el contenido JSON después.

Flujo de publicación

01 Editar o crear entradas
02 Guardar borrador y revisar la vista previa
03 Publicar la información en GitHub
04 GitHub Pages actualiza la web con el nuevo contenido

El editor se puede abrir desde una página pública, pero publicar requiere acceso de escritura al repositorio. No pongas un token en el repositorio ni lo compartas con nadie.
